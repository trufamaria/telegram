# Telegram Channel Scraper

Script for collecting posts from public Telegram channels for research on political communication.

## What it does

The script connects to the Telegram API and downloads posts from the public channels you list. It is part of my work on how political content circulates on Telegram, including a study of media operations with Dr. Ori Swed at Texas Tech University.

## Requirements

- Python 3
- Telegram API credentials, which you can request at my.telegram.org

Credentials are not included in this repository. Keep them in a separate file and never post them online.

## How to use

1. Install the required Python packages.
2. Add your API credentials in a local config file.
3. List the public channels you want to collect.
4. Run the script.

## Data and ethics

The script collects public channel posts only. Collected data is not stored in this repository. Anyone repeating the collection should follow Telegram's terms of service and their institution's research ethics rules.
